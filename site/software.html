Software

Each of these began as a need in a particular lesson. Everything here has run in front of my own classes, and most of the source is public on GitHub.

classroomtools.io

  • classroomtools.io. The collection of classroom tools built from Teaching After the Feed.
    • Close Reader. Live annotation. Students tag and annotate any shared text, and the class's readings accumulate on screen as they work.
    • Constellation Board. A Warburg-style board for arranging images in relation to one another and finding patterns across them.
    • Attention Heatmap. Shows where a class looks first on an image, poster, or artwork. Responses collect into a heatmap live as students submit them.
    • JPEG Degradation. Makes lossy compression visible by running the degradation sequence in front of the class.

Apps & platforms

  • curatewith.art. A collaborative art-browsing tool built on open museum collections. Classes search five collections at once and build shared boards in real time.
  • Cadence LMS. A teacher-facing learning management system for any subject or course.
  • ExamLock. A secure in-class exam app with a teacher dashboard and a locked-down student view.
