Software

Each of these began as a need in a particular lesson. Everything here has run in front of my own classes, and I publish the source on principle: a tool built for my room should be usable in anyone else's, and a teacher should be able to read what a piece of classroom software does before putting students in front of it.

classroomtools.io

The collection of classroom tools built from Teaching After the Feed, collected at classroomtools.io.
